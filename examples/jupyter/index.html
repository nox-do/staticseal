Ein echter Jupyter-Export mit pandas-Tabelle, Gesamtumsatz und Matplotlib-Diagramm. Ohne Python auf dem Rechner des Empfängers.

Versiegelten Bericht öffnen →HTML-Export vergleichen

Beispiel mit Quellen als ZIP herunterladen

1. Bericht erzeugen

ZIP entpacken und im Beispielordner arbeiten. bericht.ipynb verbindet erklärenden Text mit auswertung.py. Die vier Monate ergeben 6.050 €; April hat den höchsten Umsatz. 

uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python -m nbconvert --execute --to html --no-input \
  --embed-images --template-file offline.html.j2 bericht.ipynb --output bericht.html

Getestet mit Python 3.12.9. Die Paketversionen stehen in requirements.txt. Unter Windows heißt der Python-Pfad .venv\Scripts\python.exe.

--no-input blendet Programmcode aus; --embed-images bettet Bilder ein. Die kleine Vorlage offline.html.j2 entfernt unbenutzte RequireJS-, MathJax- und Mermaid-Skripte. Sie eignet sich für diesen statischen Bericht, nicht für Formeln, Widgets oder Mermaid.

2. HTML versiegeln

Der Export ist bereits eigenständig. Im Browser Staticseal öffnen, bericht.html auswählen, „Display as a webpage“ aktivieren und das Paket erstellen. Mit Passwort bleibt der Inhalt bis zum Öffnen verschlüsselt.

Alternativ aus dem Staticseal-Repository, nachdem dessen npm-Abhängigkeiten installiert wurden:

node bin/self-encrypt.mjs --in examples/jupyter/bericht.html \
  --out examples/jupyter/sealed.html --html-page --no-password

Ohne --no-password fragt die CLI nach einem Passwort. Für andere Exporte mit separatem CSS, Bildern oder klassischen Skripten --bundle statt --html-page verwenden. Das verändert die HTML-Arbeitskopie und kann Ressourcen nachladen; Warnungen prüfen.

3. Wirklich offline prüfen

Das versiegelte HTML separat kopieren, den Quellordner unzugänglich machen und das Netzwerk abschalten. Nach dem Öffnen müssen Kennzahl, alle vier Tabellenzeilen und das Diagramm erhalten bleiben. Genau dieser Vergleich wurde in Chrome geprüft.

Das öffentliche Beispiel hat kein Passwort. Es ist eine Demonstration, kein vertraulicher Bericht. Formeln, Mermaid und serverabhängige Inhalte sind damit nicht getestet.
